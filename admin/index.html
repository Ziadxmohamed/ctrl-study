إعداد مفتاح الإدارة لأول مرة
  1. افتح رابط إنشاء المفتاح أدناه من حساب مالك المستودع.
  2. اختَر Resource owner: Ziadxmohamed، ثم Only select repositories، وحدّد ctrl-study.
  3. في Repository permissions اختَر Actions: Read and write، وحدّد تاريخ انتهاء مناسبًا.
  4. اضغط Generate token وانسخه إلى حقل مفتاح الإدارة هنا.
